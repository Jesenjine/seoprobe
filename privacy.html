Privacy Policy

📄 Product: SEOProbe Chrome Extension (version 2.5) 📅 Effective date: May 12, 2026 🔄 Last updated: October 16, 2026

🔒Short version: SEOProbe has no servers and the developer does not collect, receive, sell or share any personal data. Page analysis runs inside your Chrome browser.

✅To run its checks, the extension sends requests from your browser to the website you are analyzing (and to the links found on it). Analysis results leave your browser only when you choose to export them to Google Sheets, and then they go to your own Google Drive.

This Privacy Policy applies to the SEOProbe Chrome extension and its website. It describes version 2.5 of the extension.

3How the Extension Works

When you click the SEOProbe icon, the extension:

  • 🔍Reads the current page's structure (DOM) through its content script.
  • 📊Analyzes meta tags, headings, images, links, structured data, accessibility signals, keywords and AI writing signals in your browser.
  • 🌐Sends requests to the analyzed website when a check needs it (see section 6).
  • 🧠Shows the results in the extension panel. Nothing is sent to the developer.

Two measurements run in the background while you browse, so the data is ready when you open the panel:

  • ⏱️Core Web Vitals — the content script loads on web pages and measures LCP and INP from the start of page load. The values stay in the page's memory and disappear when you leave the page.
  • ↪️Redirect chain — the webRequest API observes top-level page loads in each tab and records redirect hops and the final HTTP status code. Each tab keeps only its latest navigation. The record is removed when you close the tab and cleared when you close the browser.

SEOProbe has no backend server, no database and no cloud infrastructure of its own.

4Data Stored in Your Browser

SEOProbe uses two Chrome storage areas. Neither is synced or sent to any server by the extension.

  • 💾chrome.storage.local — your interface language (sr, en or de) and theme (light or dark). Kept until you remove the extension.
  • 🕒chrome.storage.session — temporary data: which tabs have the SEOProbe panel open, link-check and hreflang results, and the redirect chain of each tab. Cleared automatically when you close the browser.

You can remove all stored data at any time by removing the extension.

5Optional Google Sheets Export

SEOProbe can export an SEO audit or Google SERP data to a new spreadsheet in your Google Drive. This feature runs only when you click the Sheets button.

  • 🔑Authorization uses Google OAuth 2.0 through the Chrome Identity API (chrome.identity). You see Google's standard consent screen before you grant access.
  • 📁SEOProbe requests only the drive.file scope. It can access only the files it creates and cannot read any other file in your Google Drive.
  • 📤The extension sends the audit or SERP data you chose to export to the Google Sheets API (sheets.googleapis.com) to create and format the spreadsheet. The spreadsheet belongs to you.
  • 🚫The developer never receives your Google credentials, email address, OAuth token or exported data.

SEOProbe's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke SEOProbe's Google access at any time at myaccount.google.com/permissions. Spreadsheets already created stay in your Google Drive until you delete them. Revoking access does not affect the other features.

6Network Requests Made by the Extension

SEOProbe does not contact any server operated by the developer. The extension makes the following requests directly from your browser, under your own IP address:

  • 🌐The website you analyze — the page itself (raw HTML and response headers), robots.txt, sitemap files, and standard /.well-known/ discovery files used by the experimental AI agent readiness check.
  • 🔗Links found on the page — when you run the link checker, each link target receives a HEAD or GET request to read its HTTP status.
  • 🌍hreflang alternate pages — when you run the hreflang check, each alternate page is requested to verify its return link.
  • 📊Google Sheets API — only when you export to Google Sheets.

The Tools tab contains links to external SEO services (SEMrush, Google Search Console, PageSpeed Insights, GTmetrix and the Rich Results Test). They open the service's own page in a new tab only when you click them. SEOProbe does not pass the analyzed page or any other data to these services. Their own privacy policies apply once you visit them.

7Chrome Extension Permissions Explained

SEOProbe requests the following permissions. Each is used only for the stated purpose:

  • 📌activeTab — Accesses the tab you are viewing when you click the extension icon, to open the analysis panel and inject the audit script.
  • 📌scripting — Injects the analysis script into the page you audit, and re-injects it after the extension reloads or you click Refresh. The script reads page structure and highlights selected elements on the page.
  • 📌tabs — Identifies the tab and URL you are auditing, sends messages to that tab's analysis script, opens the full-size report in a new tab and restores the panel after you navigate within the same tab.
  • 📌identity — Requests Google authorization only when you click the Google Sheets export button.
  • 📌storage — Saves your language and theme locally and keeps temporary analysis state in session storage (see section 4).
  • 📌downloads — Saves the audit report as a local XLSX file when you click the XLSX export button.
  • 📌webRequest — Observes top-level page loads in read-only mode to record redirect hops and the final HTTP status code. It does not block, modify or redirect requests, and it does not read headers, cookies or request bodies.
  • 📌Host access to all sites (<all_urls>) — Lets SEOProbe audit any website you choose: fetch the page's raw HTML and headers, check the status of links found on the page, verify hreflang return links on other domains, observe redirect chains and measure Core Web Vitals from page load.
